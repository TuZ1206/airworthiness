# 第三章审查数据

本目录保存“材料性能与材料级验证”的官方来源台账、知识节点、关系、名词索引、核验摘录和审核记录。正式来源仅限中国政府网站，全部新增记录均为 `pending`，专业批准前不得导入正式 Neo4j 或 Dify。

正文采用六条主线：材料性能验证的法规基础；材料特性与材料级证据；环境影响与试验状态代表性；材料变异性和A/B基准设计值；材料规范、鉴定与验收边界；材料数据库、可追溯性及跨章接口。

## 数据边界

- `HB 8605-2021` 只支撑标准存在、题名、版本和状态；未取得政府渠道受控全文前，不引用具体章节或量化要求。
- FAA AC 20-107B、ASTM、SAE和CMH-17仅在 `review.md` 中追踪，不进入正式CSV、网页或图谱依据。
- 材料试验方法和统计计算归第九章；制造工艺控制归第四章；材料与供应商变更归第五、六章；积木式证据传递归第七章。
- 本章不设置通用样本量、温湿度、老化时间、材料强度、变异系数、配比或保存期限。

运行检查：

```bash
python -m unittest tests.test_ch03_data tests.test_chapter_data_format -v
```

`documents/` 为检索摘录，不替代官方原文。台账哈希对应本地Markdown摘录；官方附件原始哈希待稳定下载后补录。
