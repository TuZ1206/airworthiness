# 第六章 质量体系与供应链适航监管

## 范围

本章仅采用中国政府官方网站发布的现行法律、民航规章、管理程序和咨询通告，围绕以下六条主线整理：

1. 生产质量体系
2. 供应商控制
3. 设计保证系统
4. 委任代表体系
5. 监管工具
6. 复合材料制造质量体系

国际组织、国外监管机构、商业网站、博客和二次转载不作为本章正式依据。

- 数据状态：增量技术核验完成，附件原始哈希和部分2026年程序子条款仍待复核，专业审核待完成。

## 文件说明

- `sources.csv`：官方来源及效力状态。
- `nodes.csv`：法规、程序、概念和监管过程节点。
- `relations.csv`：依据、细化、操作化、延伸和衔接关系。
- `glossary.csv`：右侧名词索引。
- `documents/`：按来源编号保存的核验摘录；不是附件全文替代品。
- `review.md`：效力判断、版本沿革、争议项和阻断项。
- `crawler_config.json`：仅包含已核实的政府网站入口。

## 专业审核重点

1. 2026年新《民用航空法》与现行 `CCAR-21-R5` 在“生产机构批准书/生产许可证”术语上的过渡关系。
2. 2013年供应商管理指南在2026年生产机构制度下的继续适用边界。
3. `AP-21-31R3` 中供应商控制审查、质量系统审查和过渡安排的具体条款定位。
4. 2027年7月1日设计机构和生产机构过渡节点的准确表述。
