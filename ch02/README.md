## 文件说明

- `sources.csv`：86份中国民航局官方来源台账。
- `documents/*.md`：官方PDF机械提取正文及溯源元数据。
- `nodes.csv`、`relations.csv`：第二章全流程接口的待审核图谱数据。
- `glossary.csv`：右侧名词索引。
- `review.md`：爬虫筛选边界、风险和专业签字记录。
- `crawler_config.json`：本轮86个有效政府入口。
