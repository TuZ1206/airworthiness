A 章 总则
UM R . 2 0 0 0 条 适用范围及定义
(a ) 本标准规定了颁发和更改最大审定起飞重量不超过 3 1 8 0
千克 、 非增压 、 不用于载人飞行 、 可进行融合飞行或者在人口密
集区域上方飞行的中型和大型正常类多旋翼无人驾驶航空器系统
型号合格证 、 补充型号合格证的适航要求 。
(b ) 以下定义适用于本标准 :
(1 ) 多旋翼航空器是指一种重于空气的航空器 , 仅由三个 或
更多的以发动机驱动的升力装置 ( 如螺旋桨 、 旋翼等 ) 为航空器
飞行提供升力 , 并通过调节每一个升力装置的功率实现航空器方
向控制 。
(2 ) 多旋翼无人驾驶航空器是指一种没有机载驾驶员 、 自 备
动力系统的多旋翼航空器 。
(3 ) 多旋翼无人驾驶航空器系统是指多旋翼无人驾驶航空 器
以 及 与 其 有 关 的 遥 控 台 ( 站 ) 、 任 务 载 荷 和 控 制 链 路 等 组 成 的 系
统 。 其中 , 遥控台 ( 站 ) 是指遥控无人驾驶航空器的各种操控设
备 ( 手段 ) 以及有关系统组成的整体 。
(4 ) 无人驾驶航空器飞行机组是指控制无人驾驶航空器的 远
程操控员以及直接参与无人驾驶航空器运行的任何人员 。
(5 ) 可控应急着陆是指可能采用应急程序 , 无人驾驶航空 器
可以选择接地方向和着陆区域进行着陆 , 同时合理地保护地面人
员免受严重伤害 。 着陆时 , 无人驾驶航空器的某些损坏是可以接
— 1 —

受的 。
(6 ) 临界动力变化是指对飞行性能或操纵品质产生最不利 影
响的飞行控制系统或动力装置的单个或组合失效 , 并且这些失效
概率未被证明为极不可能发生 。
(7 ) 批准的飞行包线是指局方认为无人驾驶航空器可以安 全
运行的条件范围 。 这些条件包括但不限于重量和重心组合 、 飞行
剖面 、 环境条件以及可能发生的故障 。

飞行控制系统的设计应当 :

(b ) 防止可能的危害 ;
(c ) 能够向飞行机组提供安全操作所需的信息 ;
(d ) 保护无人驾驶航空器避免失去控制或者超过临界极限的

(1 ) 具备将起落架保持在着陆位置的可靠措施 ;

UM R . 2 3 2 5 条 防火
(a ) 在下 列情况 , 无人驾驶 航空器应当 设计成使 起火的风 险

(1 ) 由于可能的运行环境下产生的热量 、 辐射的热能或系 统
故障而引起的火灾 ;
(2 ) 易燃液体 、 气体或蒸气引起的火灾 ;
(3 ) 某些机载系统 ( 如电池系统 ) 因其特性会使火焰蔓延 或
者会成为起火源的情况 ;
(b ) 应当采取以下措施 , 使火焰蔓延的风险降到最低 :
(1 ) 自熄 、 耐火或防火材料的使用 , 应与其安装位置 、 运 行
环境和安全运行所需的防火要求相匹配 ;
(2 ) 可 行 情 况 下 , 无 人 驾 驶 航 空 器 应 当 具 有 火 情 包 容 的 设
计 , 并能够向飞行机组提供告警信息 。
(c ) 有效载荷舱的起火不应影响可控应急着陆 。
UM R . 2 3 3 0 条 火区和邻近区域的防火

(b ) 出现火情或者过热时 , 不能妨碍无人驾驶航空器可控应
急着陆 ;
(c ) 在火 区内 , 应急 程序 期间使 用的 接线 端 、 设 备和 电缆 应
当是耐火的 。
UM R . 2 3 3 5 条 闪电与静电防护
(a ) 无人 驾驶航空 器的设计 应当保护其 免受闪电 造成的灾 难
性后果 ;
(b ) 无人驾驶航空器的设计应当保护其免受静电积聚造成的
危险的后果 。
UM R . 2 3 4 0 条 外挂物
外挂物的吊挂设备应满足以下要求 :
(a ) 规定使用限制内不会对飞行安全产生不利影响 ;

(b ) 如果安全收益超过危害 , 无人驾驶航空器应当在制定的
工作包线内能够停止和重新起动动力装置 。

(a ) 能量存储和分配系统应满足以下要求 :

驶航空器系统中的系统 、 设备和安装 , 在单独考虑以及与其他系

UM R . 2 5 8 0 条 探测与避让

— 2 6 —

响降至最低 。 如需飞行机组采取措施 , 应在飞行手册的操作程序

(d ) 链路性能应防止受到外部干扰 。

R 章 遥控台 ( 站 )
UM R . 5 0 0 0 条 总则
(a ) 遥控 台 ( 站 ) 作为无人 驾驶航空器 系统的一 部分 , 用 于
对无人驾驶航空器进行指挥 、 控制 、 监控和通信 , 确保无人驾驶
航空器在预期的运行范围内安全运行 。
(b ) 申请人应确定遥控台 ( 站 ) 必要的支持条件 , 以确保飞
行机组正确履行职责 。
(c ) 申请人应制定遥控台 ( 站 ) 的使用限制和资料 。
第一节 遥控台 ( 站 )
UM R . 5 1 0 5 条 设计与构造
材料的选择和制造方法及其过程必须考虑预期服役的遥控 台
( 站 ) 的运行环境 。
UM R . 5 1 1 0 条 系统 、 设备的功能和安装
(a ) 遥 控 台 ( 站 ) 用 于 对 无 人 驾 驶 航 空 器 进 行 指 挥 、 控 制 、
监 控 和 通 信 的 系 统 、 设 备 以 及 相 应 的 功 能 和 安 装 应 满 足
UM R . 2 5 0 0 、 UM R . 2 5 0 5 、 UM R . 2 5 1 0 的要求 。
(b ) 除 (a ) 款 以 外 的 遥 控 台 ( 站 ) 的 其 他 系 统 、 设 备 ( 包
括提供支持条件的系统 、 设备 ) 的设计和安装应确保其运行不会
对无人驾驶航空器系统安全运行造成不利影响 。
UM R . 5 1 1 5 条 飞行机组界面
(a ) 遥 控 台 ( 站 ) 的 设 备 和 布 局 ( 包 括 操 控 员 视 界 的 设 计 )

(c ) 飞行 机组控 制无 人驾 驶航空 器的 操作 应当简 便 、 平稳 和
确切 , 用于机组控制操作必需的装置在其工作位置上是可达的 。
UM R . 5 1 2 0 条 飞行机组界面设备的安装和使用
(a ) 遥 控 台 ( 站 ) 与 飞 行 机 组 界 面 相 关 的 每 个 已 安 装 设 备 ,
都应当进行标识 ( 如果适用 ) , 说明其名称 、 功能或者使用限制 ,

戒备及正常指示 。
(c ) 应当 及时向 负责 采取 纠正措 施的 飞行 机组成 员提 供涉 及
无人驾驶航空器不安全运行状态 、 链路性能降级和遭受安保威胁
的信息 。 这些信息应当足够清晰以避免可能的机组成员差错 。

(a ) 每个机组成员的工作量 ;
(b ) 对无人驾驶航空器和链路重要参数的监控 ;
(c ) 对无人驾驶航空器的指挥和控制 ;

(b ) 飞行机组对无人驾驶航空器的指挥 、 控制 、 监控和通信
功能不会受到不利影响 。

应提供充分的手段 , 以防止外部源对遥控台 ( 站 ) 未经授 权
的物理 、 电子 、 网络访问 , 避免通过遥控台 ( 站 ) 使无人驾驶航

UM R . 5 1 5 5 条 遥控台 ( 站 ) 的切换

(b ) 不同遥控台 ( 站 ) 切换期间必须保持可靠控制且不能对
无人驾驶航空器飞行安全产生不利影响 ;
(c ) 遥控 台 ( 站 ) 对 于无 人驾驶 航空 器的 飞行控 制权 , 同 一

第二节 遥控台 ( 站 ) 的支持条件
UM R . 5 2 0 0 条 工作环境和人为因素
(a ) 遥 控 台 ( 站 ) 的 工 作 环 境 应 当 考 虑 温 度 、 湿 度 、 噪 声 、
振动 、 通风 、 照明和飞行机组的生理适应性等因素 , 不得对飞行
机组履行职责能力产生不利影响 。
(b ) 应当为飞行机组提供充分 、 适当的座位或者工作位 , 并
注意减少在运行期间与周围结构接触造成伤害的可能性 。
(c ) 对于 要求视 距内 飞行 的无人 驾驶 航空 器 , 需 提供 飞行 机
组在所有飞行阶段能目视观察到无人驾驶航空器的条件 。
UM R . 5 2 0 5 条 电力供应
(a ) 供电 系统必须 设计成能 在遥控台 ( 站 ) 正常 工作期间 供
电 , 且不会导致不安全状况 。
(b ) 在遥控台 ( 站 ) 正常工作期间 , 对飞行机组正确履行职
责 、 确保无人驾驶航空器安全运行所需的负载应提供可靠不间断
的电源 。
UM R . 5 2 1 0 条 防火
(a ) 应 当 采 取 措 施 , 尽 量 降 低 遥 控 台 ( 站 ) 产 生 火 灾 风 险 ,
以及火灾导致的烟雾和有毒气体危害 。
(b ) 应当采取措施保护飞行机组免受火灾 、 烟雾和有毒气体
的不利影响 。
(c ) 必须为飞行机组提供防火手段 。
(d ) 应当有扑灭遥控台 ( 站 ) 任何火情的措施 。

(b ) 防止静电电荷的危险积累 。
UM R . 5 2 2 0 条 危险防护和安全设备
(a ) 遥控 台 ( 站 ) 应该充分 考虑到自身 可能存在 的风险和 来

控台 ( 站 ) 系统和飞行机组人员危害程度 。
(b ) 遥控台 ( 站 ) 应对飞行机组可能遭遇的危险提供必要的
安全设备 。
(c ) 遥 控 台 ( 站 ) 供 飞 行 机 组 使 用 的 安 全 设 备 , 应 当 可 靠 、

UM R . A 4 适航限制章节
持续适航文件应当包含标题为适航限制的章节 , 该章节应 当
单独编排并与文件的其他部分明显地区分开来 。 该章节必须规定
型号合格审定所要求的强制性更换时间 、 结构检查时间间隔和有
关的结构检查程序 。 如持续适航文件由多本文件组成 , 则本条要
求的适航限制章节内容应当列入主要手册中 。 申请人应当在该章
节 显 著 位 置 清 晰 声 明 : “ 本 适 航 限 制 章 节 已 经 中 国 民 用 航 空 局 批
准 , 规定了涉及民航管理的规章有关维修和运行的条款所要求的
维修要求 , 如果局方已另行批准使用替代的大纲则除外 。 ”
