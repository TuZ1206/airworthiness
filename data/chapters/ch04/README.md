# 第四章审查数据

本目录保存“制造工艺与工艺验证”的官方来源台账、知识节点、关系、名词索引、清洗摘录和审核记录。正式来源仅限 `gov.cn` 或 `.gov.cn`，全部新增记录均为 `pending`，专业成员批准前不得导入正式 Neo4j 或 Dify。

正文采用六条主线：制造方法适航基础、成型环境与固化控制、工艺规范和工艺窗口、工艺鉴定与变更再鉴定、缺陷控制与无损检测、制造符合性与记录及偏离处置。

运行检查：

```bash
python -m unittest tests.test_ch04_data
```

`documents/` 中的文件是便于审查的清洗摘录，不替代官方原文。`sources.csv` 的哈希对应这些清洗摘录；附件原始哈希待官方附件可稳定下载后补录，并已列入 `review.md` 阻断项。
