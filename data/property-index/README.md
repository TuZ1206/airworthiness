# 结构特性目录映射

`source-map.csv` 将九章全部 189 条来源按以下顺序组织：强度与承载、刚度与稳定性、冲击与损伤、疲劳与寿命、环境适应性、制造与一致性、通用适航与管理流程。同一来源可关联多个目录；当前共 203 条映射。第七类收纳法规层级、审定、更改和委任等不能准确归入材料性能的资料。

表内 `source_id` 仍指向原始章节来源；`property_id` 是浏览目录；`sort_order` 决定页面顺序；`mapping_status=pending` 表示归类尚待专业核验；`mapping_note` 说明初次归类理由。初稿按章节和标题编排，**不能据此推断文件所有条款都适用于该结构特性**。专业审核时应按具体条款拆分和补充多重关联，尤其检查通用法规、材料环境条件及损伤容限资料。

SQLite 重建时验证每条来源至少有一个映射，拒绝不存在的来源、目录和重复的来源—目录组合。原九章 CSV、正文哈希、来源编号及知识图谱审核状态保持不变；本目录只改变检索和展示顺序。

节点、关系和术语按各自 `source_id` 继承特性归类，写入重建数据库的 `property_entity_map`；607 个原实体形成 881 条目录关联。此为资料导航关联，不表示节点或关系已经通过专业审核。

本地样版可用 `python scripts/build_property_preview.py` 刷新。`scripts/seed_property_index.py` 仅用于生成最初草案，默认拒绝覆盖现有映射；人工审核开始后不得重新生成覆盖结果。
