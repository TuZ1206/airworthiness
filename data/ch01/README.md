# 第一章 复合材料适航法规体系概论

本目录依据原稿《复合材料适航法规体系概论》整理，并按仓库统一接口建立第一章来源、节点、关系和术语数据。原稿只用于识别主题和待核验引用，不作为正式来源。全部新增记录保持 `review_status=pending`。

<a id="scope"></a>
## 适用范围与基本概念

以现行《中华人民共和国民用航空法》和《无人驾驶航空器飞行管理暂行条例》核验民用航空器、无人驾驶航空器和适航许可范围。

<a id="hierarchy"></a>
## 中国适航法规层级

以法律、行政法规、民航规章、规范性文件和政府标准平台可核验标准构成第一章正式资料范围。层级关系是便于理解的章节组织方式，不替代各文件的法定效力判断。

<a id="initial-airworthiness"></a>
## 初始适航与证件链

围绕型号设计批准、生产批准、适航批准和型号合格审定程序建立证据链。

<a id="technical-standards"></a>
## 产品技术标准

覆盖正常类飞机、运输类飞机、正常类与运输类旋翼航空器、航空发动机和技术标准规定项目批准。

<a id="continued-airworthiness"></a>
## 持续适航与监督机制

覆盖持续适航、安全改进、适航指令、维修单位合格审定和适航委任体系。

<a id="supplements"></a>
## 规范性文件 标准与国际合作接口

覆盖AP、AC、MD的管理边界、专用条件、复合材料指南、行业标准状态和双边适航文件目录。国际组织、外国法规和企业案例只进入 `review.md` 的原稿引用追踪。

## 文件说明

- `sources.csv`：21项中国政府官方来源台账。
- `documents/*.md`：各来源的官方元数据和本章相关核验摘录。
- `nodes.csv`、`relations.csv`：第一章26个节点、26条关系组成的法规体系和生命周期接口待审核图谱数据。
- `glossary.csv`：第一章右侧名词索引。
- `review.md`：版本纠错、国外引用隔离和专业签字记录。
- `crawler_config.json`：已核实政府入口。
